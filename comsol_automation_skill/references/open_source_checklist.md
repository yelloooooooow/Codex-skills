# Open Source Checklist

Before publishing:

- Remove `.mph`, `.docx`, `.pdf`, raw Java exports, logs, videos, and generated artifacts unless explicitly sanitized.
- Run privacy scan.
- Replace private paths with config placeholders.
- Remove credentials, server access details, and license details.
- Confirm examples use generic synthetic parameters.
- Confirm reports do not include private project names or unpublished data.
- Confirm Java examples are toy snippets or sanitized summaries only.
