# Validation Guidelines

Use precise terms:

- Verification checks implementation.
- Validation compares against equivalent reference data.
- Calibration adjusts parameters against reference data.
- Sensitivity analysis perturbs inputs.
- Uncertainty analysis documents non-equivalence and missing information.

Do not call a result validated unless geometry, physics, boundary conditions, initial conditions, material parameters, and output definitions are comparable. If reference data are incomplete, use qualitative comparison or sanity checks.
