# Output File Standards

## Core Folders

```text
results/
results_calibrated/
optimization_results/
economic_results/
figures/
videos/
screenshots/
reports/
paper_assets/
audit/
logs/
```

## Naming

Use case and variant in filenames:

```text
case_A_baseline_results.mat
case_A_optimized_results.mat
case_A_original_vs_calibrated.png
```

## Minimum Outputs

- raw result files;
- summary CSV;
- final figures;
- video index if animations exist;
- audit report;
- final report narrative;
- figure and table lists.
