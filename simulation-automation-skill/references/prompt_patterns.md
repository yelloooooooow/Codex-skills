# Prompt Patterns

## Simulink

Ask for model goal, cases, parameters, logged signals, solver settings, and expected plots. Request permission before changing existing model logic.

## Fluent

Ask for geometry, named boundaries, materials, models, solver settings, output interval, and software paths. Always require an environment check.

## Coupled Calibration

Ask which model owns system behavior and which CFD outputs can be fairly compared. Require original and calibrated outputs in separate folders.

## Optimization

Ask for baseline, variables, constraints, objectives, and whether economics are coupled.

## Final Review

Ask whether to rerun missing modules or only audit existing outputs. Preserve original results.
